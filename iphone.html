1

Requisitos do iPhone

Antes de começar, confira os requisitos do seu iPhone. Verifique a versão do sistema, o espaço livre disponível e a sua conexão com a internet, porque o processo precisa de uma rede estável. Libere espaço no aparelho e feche aplicativos que você não está usando. Entenda cada etapa antes de começar: o guia explica os requisitos e o processo com calma, para você entender o que vai acontecer em cada passo. Se o aparelho não atender aos requisitos, resolva isso primeiro — tentar avançar sem os requisitos é a causa mais comum de problemas na instalação.

2

Instalação passo a passo

A instalação no iPhone segue o guia passo a passo. Leia cada etapa com atenção e faça na ordem, sem pular nenhuma. Depois de concluir a instalação, abra o aplicativo e confira se ele abre normalmente antes de tentar qualquer script. Só depois dessa verificação, abra o jogo e execute o seu primeiro script. Comece com scripts simples, de fontes conhecidas, e só depois avance para scripts mais complexos. Essa ordem evita a maioria dos problemas que os iniciantes encontram. Se alguma etapa não funcionar como esperado, volte ao início dela e refaça com calma em vez de tentar atalhos.

3

Como executar scripts no iPhone

Executar um script no iPhone é simples. Copie o código do script que você quer usar, abra o executor, cole o código na área indicada e toque em executar. O script passa a rodar dentro do jogo. Se nada acontecer, confira se o código está completo e se a versão do aplicativo está atualizada, porque scripts desatualizados são uma das causas mais comuns de falha. Prefira scripts de fontes conhecidas e evite copiar códigos de qualquer lugar sem verificar a origem, porque um código mal feito pode travar o jogo ou não funcionar como esperado. Guarde os seus scripts favoritos para executar novamente sem precisar copiar tudo outra vez.

4

Problemas comuns e como resolver

Os problemas mais comuns têm solução simples. Se o aplicativo não abre, verifique se a instalação foi concluída corretamente e se o aparelho atende aos requisitos. Se o script não executa, confira se o código está completo e atualizado. Se o jogo fecha sozinho, feche outros aplicativos em segundo plano e tente novamente. Manter o aplicativo atualizado resolve boa parte dos problemas, porque cada versão corrige falhas das anteriores. Quando o erro persistir, revise as etapas do guia uma a uma: na maioria das vezes, o problema está em um passo pulado ou feito fora de ordem.
